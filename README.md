## Sobre

Tenho interesse em desenvolvimento web e estou evoluindo com projetos que combinam estruturação de páginas, estilização, responsividade, interatividade com JavaScript e primeiros passos em Python.

Meu objetivo é aprofundar meus conhecimentos em desenvolvimento full stack, principalmente explorando:

- Construção de interfaces modernas e responsivas;
- JavaScript aplicado em projetos reais;
- Python para lógica, automações e back-end;
- Consumo e criação de APIs;
- Organização de projetos no GitHub;
- Boas práticas de versionamento e documentação.
